# Benchmarks

Awaiten wires the graph at build time, so there is nothing to reflect over at runtime. These benchmarks compare it against
[Microsoft.Extensions.DependencyInjection](https://learn.microsoft.com/dotnet/core/extensions/dependency-injection),
[Autofac](https://autofac.org/),
[DryIoc](https://github.com/dadhi/DryIoc) and
[Simple Injector](https://simpleinjector.org/) across the same graphs. Pick a scenario; every multiple is relative to Awaiten.

<AwaitenBenchmarkResult />

<details>
<summary>How these numbers are measured</summary>

- **Suite**: [`Awaiten.Benchmarks`](https://github.com/awaiten-dev/Awaiten/tree/main/Benchmarks/Awaiten.Benchmarks) driven by [BenchmarkDotNet](https://benchmarkdotnet.org/).
- **Job**: `MediumRun` with the in-process toolchain.
- **Runner**: `ubuntu-latest` GitHub Actions agent, refreshed on every push to `main`.
- **Sizes**: Build and Resolve are measured at container sizes of 8 and 256 registrations.
- **Trend**: the recent runs compare each container with Awaiten in the same run, so the line does not depend on the speed of the runner. The dashed line marks equal time.

</details>
